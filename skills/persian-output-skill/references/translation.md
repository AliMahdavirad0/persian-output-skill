# English to natural Persian

## Understand and draft

For a short ordinary phrase or paragraph, translate and check fidelity directly. Do not load the example bank, glossary or every format reference, create scratch files, or launch artifact audits unless the request actually needs them. Read register guidance when the audience or source voice is unclear; use a user-specified register directly.

Read the complete available source before translating. Identify the audience, genre, argument, pronoun references, idioms, and terminology. For a URL, retrieve the actual article/page, including relevant captions and headings; a search snippet is not the source. Report inaccessible portions instead of inventing them.

Translate meaning in coherent sentences or paragraphs, rather than individual DOM text nodes or word-for-word substitutions. Use Persian clause order and collocations while preserving what each clause claims. Keep source headings, paragraphs, lists, figures, tables, links, footnotes, and citations unless the user requests a structural rewrite. If the user supplied a glossary, use it first; then established domain terminology, then a context-appropriate ordinary equivalent.

For terminology only when needed, read [the seed glossary](../data/glossary.json). It is illustrative and context-specific, not an exhaustive or authoritative dictionary. For worked pitfalls, read [translation examples](../data/translation-examples.json). Do not load either for an unrelated RTL-only task.

## Check source fidelity

Review the translation against the source before polishing its style:

- Keep negation, exceptions, conditions, causality, comparison, time, agency, and scope.
- Preserve uncertainty: may/could/suggest are not guarantees; up to/at least/about are not exact quantities.
- Keep numbers, identifiers, units, names, dates, citations and link targets accurate. Do not convert units or calendars unless requested.
- Translate idioms for the actual meaning in context. Do not translate a literal technical phrase as an idiom just because the words match one.
- Resolve pronouns from evidence. Ask a short question if a consequential ambiguity cannot be resolved; never silently invent a referent.
- Preserve quotations' role and attribution. If the user asks to translate a quoted passage, translate its contents faithfully; otherwise keep quotations designated as verbatim unchanged.

Then read the Persian on its own for grammar, rhythm, register and consistency. This second pass must not strengthen claims, remove details, or add an explanation not present in the source. Back-translation can help reveal a discrepancy but is not proof of correctness.

## Deliver

Return the translated content or artifact. Explain only material terminology choices or missing-source limitations; do not attach every draft or internal review. For an article/site/file, also follow [layout preservation](preserve-layout.md). Naturalness, fidelity, mechanics and presentation are separate acceptance dimensions.

Evaluation sources: [MQM error typology](https://www.themqm.org/mqm-pillars/typology/) and [Agent Skills evaluation guidance](https://agentskills.io/skill-creation/evaluating-skills).
